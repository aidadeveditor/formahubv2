Module 2 : Planification, Framework Scrum & User Stories

🎯 Objectifs pédagogiques

  • Comprendre les rôles Scrum (PO, SM, Dev)
  • Rédiger des User Stories avec critères d'acceptation
  • Piloter des sprints itératifs

1. Les rôles Scrum

Le Product Owner porte la vision et priorise la valeur. Le Scrum Master facilite la méthode. L'équipe réalise.

2. La User Story canonique

'En tant que [rôle], je veux [action] afin de [bénéfice métier].' avec sa Definition of Done.

3. Les Cérémonies Scrum

Sprint Planning, Daily Stand-up (15 min), Sprint Review et Rétrospective d'amélioration continue.

🛠️ Exercice pratique

Rédigez 2 User Stories complètes pour une fonctionnalité de panier e-commerce.

🧠 Quiz d'auto-évaluation

Sélectionnez la bonne réponse pour valider vos acquis. Le feedback immédiat vous expliquera les concepts clés.
