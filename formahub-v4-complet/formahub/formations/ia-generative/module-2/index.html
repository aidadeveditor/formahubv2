Module 2 : Fondamentaux du Prompt Engineering (Les 5 Piliers)

🎯 Objectifs pédagogiques

  • Maîtriser le framework des 5 piliers
  • Définir un Persona contextualisé
  • Poser des contraintes négatives strictes

1. Les 5 Piliers d'un prompt

Rôle / Persona, Contexte métier, Tâche précise, Contraintes positives et négatives, Format de sortie attendu.

2. Persona & Contexte

Ancrer le modèle dans un univers d'expertise précis pour éliminer les réponses génériques.

3. Contraintes négatives

Interdire les formules robotiques, les superlatifs creux et calibrer strictement la longueur.

🛠️ Exercice pratique

Rédigez un prompt complet respectant les 5 piliers pour générer un post LinkedIn sans jargon.

🧠 Quiz d'auto-évaluation

Sélectionnez la bonne réponse pour valider vos acquis. Le feedback immédiat vous expliquera les concepts clés.
