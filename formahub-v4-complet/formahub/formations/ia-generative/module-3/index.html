Module 3 : Techniques avancées : Few-Shot & Chain-of-Thought

🎯 Objectifs pédagogiques

  • Déployer le Few-Shot Prompting avec exemples
  • Utiliser le Chain-of-Thought pour les raisonnements
  • Extraire des schémas JSON structurés

1. Zero-Shot vs Few-Shot

Fournir 2 à 4 exemples d'entrée/sortie explicites pour formater précisément le ton et la structure attendus.

2. Chain-of-Thought

Forcer le modèle à verbaliser ses étapes d'analyse intermédiaires avant de conclure, réduisant les erreurs de logique.

3. Sorties JSON strictes

Standardiser la donnée pour son interopérabilité directe dans des applications logicielles.

🛠️ Exercice pratique

Concevez un prompt Few-Shot incluant 2 exemples pour classifier des retours clients au format JSON.

🧠 Quiz d'auto-évaluation

Sélectionnez la bonne réponse pour valider vos acquis. Le feedback immédiat vous expliquera les concepts clés.
