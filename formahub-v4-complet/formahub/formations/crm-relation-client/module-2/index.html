Module 2 : Pipeline Commercial, Gestion des Opportunités & Forecasting

🎯 Objectifs pédagogiques

  • Structurer les étapes du cycle de vente
  • Calculer le prévisionnel pondéré (Weighted Pipeline)
  • Maîtriser les Forecast Categories et motifs de perte

1. Étapes du pipeline

Qualification, Démonstration, Devis envoyé, Négociation finale, Clôture gagnée/perdue avec critères de sortie stricts.

2. Prévisionnel pondéré

Valeur pondérée = Montant estimé x Pourcentage de probabilité d'étape.

3. Forecast Categories et motifs de perte

Pipeline, Best Case, Commit (engagement ferme), Closed. Renseignement obligatoire du Loss Reason pour progresser.

🛠️ Exercice pratique

Calculez le CA pondéré d'un portefeuille de 3 opportunités à différents stades de maturité.

🧠 Quiz d'auto-évaluation

Sélectionnez la bonne réponse pour valider vos acquis. Le feedback immédiat vous expliquera les concepts clés.
