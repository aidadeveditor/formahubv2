Prompts Métiers pour le Content Specialist

Industrialiser la rédaction de fiches de deals, l'audit de charte et la génération de variantes publicitaires en e-commerce.

Non commencé

🎯 Objectifs pédagogiques

  • Automatiser la production de fiches offres e-commerce
  • Créer un prompt d'audit de conformité éditoriale
  • Générer des déclinaisons d'accroches pour tests A/B

1. Production de fiches d'offres e-commerce

Combinez les données brutes du partenaire (horaires, prestations, restrictions) avec un prompt métier pour générer un texte attractif conforme aux obligations légales.

2. Prompts d'audit et de contrôle qualité

Utilisez l'IA comme second relecteur en lui fournissant votre grille d'évaluation qualité pour détecter les incohérences ou le jargon technique.

3. Déclinaisons d'accroches et tests multivariés

Générez en quelques secondes des variantes axées sur différents leviers psychologiques (urgence, économie, expérience d'exception).

🛠️ Exercice pratique d'application

À partir d'un contrat de spa fictif, concevez le prompt générant une description commerciale conforme et 3 titres d'emails percutants.
